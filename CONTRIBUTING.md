# Contributing

Issues and pull requests that report reproducible defects or improve public
documentation are welcome for review. The project is not accepting external code
contributions yet because copyright assignment, DCO/CLA, and operating-entity
controls remain unresolved. Do not submit code you do not have the right to
license under Apache-2.0.

Never include customer/employer material, real tenant or subscription IDs,
deployment output, credentials, private proof evidence, or non-synthetic data.
Local changes must pass `pnpm validate` under Node.js 22.
